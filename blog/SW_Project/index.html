Introduction: What Is Cellular Segmentation? Why Does It Matter?

Cellular segmentation is the process of partitioning image pixels into distinct groups, or Regions of Interest (ROIs), where each region corresponds to an individual cell or nucleus. Rather than simply detecting where cells exist, segmentation precisely delineates their boundaries, enabling downstream quantitative analysis.

This technique has found application across a wide range of fields including medical imaging analysis: identifying tumor boundaries, counting cells in histology slides; autonomous vehicle vision: object boundary detection in real-time scenes; microscopy & biology: tracking cell morphology, division, and migration.

One of the most compelling and fast-growing applications of cellular segmentation is in spatial transcriptomics, a field that allows biologists to study gene expression while preserving the spatial context of cells within a tissue, down to single-cell resolution. Accurate cell segmentation is the first gate of most spatial transcriptomics pipelines. Every downstream analysis (cell type calling, cell–cell interaction mapping, and spatial niche detection) depends on correctly assigning molecules to individual cells.

Pipeline Overview

  1. Dataset generation: Self-produced fluorescent microscopy images of HeLa stained with a combination of fluorescent dyes, including Hoechst 33342 (Thermo Fisher, H3570), Calcein AM, Propidium Iodide (PI), BODIPY, WGA (Wheat Germ Agglutinin), Phalloidin, Concanavalin A (ConA), and SYTO dyes.
  2. Preprocessing: Background correction, illumination normalization, and boundary-cell removal using ImageJ
  3. Pre-trained model predictions: Cell detection with a pre-trained model or generalist algorithm
  4. Model training: Fine-tuning Ilastik and Cellpose on a subset of the HeLa cell images
  5. Fine-tuned model predictions: Cell detection with the fine-tuned model
  6. Evaluation: F1 scores, contour extraction, and cell-size statistics

Model Evaluation

Three algorithmically distinct tools — Ilastik, fine-tuned Cellpose, and Segment Anything — are compared below, along with previews of their segmentation outputs. ROIs identified in Ilastik are generally accurate with an F1 score of 0.7708; however, it overestimates the boundaries resulting in segmented masks that are larger than the ground-truth masks. Cellpose produces masks that closely align with the ground-truth masks. Even though individual masks yield a higher F1 score, crucial masks around the borders of the image are missing, averaging to an F1 score of 0.8773. The SAM model performs accurately but adds unnecessary additional masks in some locations, leading to an average F1 score of 0.7379.

Ilastik is a relatively simple machine learning model built on Random Forests and requires “shallow learning” annotations for either automated or manual feature selection. On the other hand, Cellpose is a deep learning U-Net–based generalist model that can be fine-tuned using additional annotations. Each model involves tradeoffs. Cellpose automates many steps, which has helped make it one of the most widely used tools for upstream spatial transcriptomics processing due to its ease of use, reproducibility across users, and strong accuracy.

However, as automation increases, reproducibility often improves at the cost of manual control. In this image set, Ilastik with manual feature selection reaches an F1 score of 0.8874, a considerable improvement over automatic feature selection, which achieved 0.8353. While manual control can improve accuracy in the hands of an experienced user, it also requires additional time and expertise.

Even with a more automated deep learning approach such as Cellpose, the output remains highly dependent on hyperparameter selection and fine-tuning. Cellpose currently offers multiple generalist models built for segmenting on cytoplasm or nuclei. In this example, we see Cellpose accuracy jumps from an F1 score of 0.67826 using the generalist algorithm to 0.8773 when fine-tuned on just one set of similar images. This performance also depends on the quality and consistency of the annotator who produces the ground-truth labels.

In essence, each software tool and algorithm type comes with its own design goals and tradeoffs. When utilizing these tools, it is important to evaluate their performance using metrics such as the F1 score, since segmentation quality directly and significantly affects downstream analyses drawn from the data.

Web Application Integration

After benchmarking segmentation approaches, I focused on translating these results into a practical tool that could support users without programming experience. As a computational biologist, I strongly believe in interdisciplinary collaboration, but also in making these powerful tools available to everyone, including biologists with limited coding experience. Therefore, I wanted to make Cellpose segmentation outputs easily accessible and interactive for both visualization and analysis.

Features

  • Image upload: Upload an image file (.tiff, .png, .jpg, etc.) along with the Cellpose .npy file
  • Mask overlay viewer: Interactively toggle between the raw image, segmentation mask, and instance labels
  • Feature extraction: Cell sizes, cell centers, and intensity by image channel

The website is hosted at https://sw-cellvis.onrender.com/ and may take a few minutes to load after inactivity due to free-tier hosting. The source code is available on GitHub below.

Conclusion and Takeaways

  • No single segmentation tool is universally best for all applications, since algorithms differ in design and intended use.
  • The tradeoff between reproducibility and manual control becomes more apparent as segmentation workflows become more automated.
  • My web application lowers the barrier to entry for biologists who want to apply segmentation tools to microscopy images without writing code.

Cellular segmentation is an ever-evolving field, with new tools and methods continuing to emerge. My work in this area is ongoing, so feel free to reach out for more information!
