Introduction: What is Cellular Segmentation? Why does it Matter?

Cellular segmentation is the process of partitioning image pixels into distinct groups, or Regions of Interest (ROIs), where each region corresponds to an individual cell or nucleus. Rather than simply detecting where cells exist, segmentation precisely delineates their boundaries, enabling downstream quantitative analysis.

This technique has found application across a wide range of fields including Medical imaging analysis: identifying tumor boundaries, counting cells in histology slides; Autonomous vehicle vision: object boundary detection in real-time scenes; Microscopy & biology: tracking cell morphology, division, and migration

One of the most compelling and fast-growing applications of cellular segmentation is in spatial transcriptomics, a field that allows biologists to study gene expression while preserving the spatial context of cells within a tissue, down to single-cell resolution. Accurate cell segmentation is the first gate of most spatial transcriptomics pipelines. Every downstream analysis (cell type calling, cell–cell interaction mapping, and spatial niche detection), depends on correctly assigning molecules to individual cells.

Pipeline Overview

  1. Dataset Generation: Self-produced fluorescent microscopy images of HeLa stained with a combination of fluorescent dyes, including Hoechst 33342 (ThermoFisher, H3570), Calcein AM, Propidium Iodide (PI), BODIPY, WGA (Wheat Germ Agglutinin), Phalloidin, Concanavalin A (ConA), and SYTO Dyes.
  2. Preprocessing: Background correction, illumination normalization, boundary cell removal using ImageJ
  3. Pre-trained model predictions: Cell detection with pre-trained model or generalist algorithm
  4. Model training: Fine tuning using Ilastik and Cellpose using a subset of the HeLa cell images
  5. Fine-tuned model predictions: Cell detection with fine-tuned model
  6. Evalution: F1 Scores, Contour extraction, Cell size statistics

Model Evaluation

Three algorithmically unique software: Ilastik, fine-tuned Cellpose, and Segment Anything and a preview of their segmentation outputs are shown below. ROIs identified in Ilastik are generally accurate with an F1 score of 0.7708; however, it overestimates the boundaries resulting in segmented masks that are larger than the expected truth masks. Cellpose produces masks that closely align to the ground truth masks. Even though individual masks yield a higher F1 score, crucial masks around the borders of the image are missing, averaging to an F1 score of 0.8773. The SAM model performs accurately but adds unnecessary additional masks in some locations, leading to an average F1 score of 0.7379.

Ilastik represents a simple Machine Learning model build upon Random Forest which requires “Shallow Learning” annotations for either automated or manual feature selection. On the other hand, Cellpose is a Deep Learning UNet based generalist model with the ability to fine-tune through additional annotations. Each model provides tradeoffs with Cellpose additionally automating many steps, becoming the most popular cellular segmentation software for Spatial Transcriptomics upstream processing due to the ease of use and reproducibility between users with high accuracy.

Though with additional automation, while reprodubility is incrased, you loose the ability to apply manual control. Here, we see that on this set of images, Ilastik with Manual Feature selection reaches an F1 score of 0.8874, a considerable increase from automatic feature selection: 0.8353. While manual control is beneficial and can result in higher accuracy with the trained eye, you must commit additional time and have the expertise necessary.

Even with more automated Deep Learning with Cellpose the output is highly dependent on hyperparameter selection as well as fine-tuning. Cellpose currently offers multiple generalist models built for segmenting on cytoplasm or nuclei. In this example, we see Cellpose accuracy jumps from an F1 score of 0.67826 using the generalist algorithm to 0.8773 when fine-tuned on just one set of similar images. This accuracy can also be attributed and varied with the accuracy of the annotater making the ground truths.

In essense, each software and algorithm type comes with its own intentions and tradeoffs. When utlizing these tools, it is important to note their accuracy through metrics such as the F1 score, as their accuracy will affect the quality of downstream analysis and the conclusions drawn from that data.

Web Application Integration

As a computational biologist, I strongly believe in working with people from multiple domains but also making these amazing tools avaliable to everyone, including biologists with limited coding experience. Therefore, I wanted to make Cellpose segmentation outputs easily acessible and interactive for both visualization and analysis.

Features: - Image Upload: Simply upload image file (.tiff, .png, .jpg, etc.) and the Cellpose .npy file - Mask Overlay Viewer: Interactive toggle between raw image, segmentation mask, and instance labels - Feature Extraction: Cell sizes, Cell Centers, and Intensity by Image Channel

The website itself is no longer active, but the codes are avaliable on Github linked below.

Conclusion and Takeaways

  • No single segmentation tool is universally best for all applications as their algorithms and intended purposes differ
  • A tradeoff between reproducibility and manual control becomes more apparent as these processes are more automated
  • My developed web application dramatically lowers the barrier to entry for biologists who want to apply segmentation tools to their microscopy images without writing code
